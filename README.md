# The Event Studio — Event Center Website

A multi-page event center website built with HTML, CSS, and JavaScript as part of a fullstack development bootcamp project.

## Pages

- **index.html** — Home page with hero section, featured events, and contact form
- **about.html** — Venue history, mission, core values, and team
- **events.html** — Full event schedule table, ticket pricing, and booking
- **privacy.html** — Privacy policy
- **terms.html** — Terms of service

## Features

- Responsive layout across desktop, tablet, and mobile
- Hamburger navigation menu for tablet and mobile screens
- CSS custom properties for consistent theming
- Hover and focus effects on all interactive elements
- Fade-in animation on hero and key sections
- Semantic HTML throughout
- Font Awesome icons for social links
- Sticky header navigation
- Hero section with background image and dark overlay
- Legal pages with privacy policy and terms of service

## Tech Stack

- HTML5
- CSS3 (Flexbox, CSS Grid, custom properties, media queries)
- Vanilla JavaScript
- Font Awesome 6.4.0 (CDN)

## How to View

1. Clone or download this repository
2. Open `index.html` in any modern browser
3. No build tools or installs required
